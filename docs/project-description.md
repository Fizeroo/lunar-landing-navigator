# Project description

Lunar Landing Navigator helps mission planners, educators and the public understand the trade-offs between a lunar site and a date. Two south-polar reference points share one UTC timeline. Users compare Sun visibility, geometric Earth visibility and overlapping windows, then save equal-duration scenarios to compare another site or a later start date.

The same prepared NASA/JPL SPICE vectors drive the globe's light, local azimuth/altitude, reference-horizon intervals, countdowns and event navigation. Moon overview, a clearly schematic space view and an interactive surface camera share one time state. A small real LRO LOLA patch demonstrates local terrain blocking with spherical curvature and explicit insufficient-coverage states. Source metadata and uncertainty are visible instead of implying global terrain coverage or operational guarantees.

The application runs locally in a browser with prepared data spanning October2026–February2027; it makes no external astronomy request while moving the time slider. Scenarios are stored locally and can be exported as validated public JSON or shared in a URL fragment. The model does not calculate electrical power, a guaranteed radio link, eclipse-aware illumination or landing safety.

Claude Code and Codex assisted development. Numerical checks, related-model Horizons comparisons, automated regressions and browser evidence are documented.

This mapping distinguishes astronomical inputs, reference comparisons, appearance and actual elevation data. Dataset files carry exact versions/hashes and generation details. The prepared DEM and its extraction are described in [scientific validation](science-exploration.md).

The prepared LOLA subset contains 101 by 101 source pixels at 80 m spacing, about 8 km across. Heights are relative to the 1,737,400 m sphere. Product metadata, pixel-centre convention, frame alignment, extraction and original source hashes are retained with the terrain asset and validation documentation. Outside that scientific coverage, the drawing has separately labelled coarser real context; unsupported scientific analyses use the explicitly chosen reference model, with no silent terrain substitution. A local found blocker and a certified unobstructed horizon are different claims.

The immersive explorer uses the same valid DEM triangles for rendering, continuous ground sampling and local obstruction rays. Its rendered sample-centre hull is 8000 by 8000 projected metres; the raster pixel footprint is 8080 by 8080 metres. See [exact coverage and search limits](immersive-data-scope.md). Candidate search evaluates a reproducible 5 by 5 grid inside a smaller named region at the displayed time and observer height. Reference-sphere lighting ranking is separate from local terrain blockage and insufficient-coverage diagnostics. No local hit does not certify a clear distant horizon. First-person walking is a visualization on an 80 m mesh, not a safe-route or rock-scale model.

## Official-source recheck

On 15 November 2026, the official [2026 challenge URL](https://www.spaceappschallenge.org/2026/challenges/lunar-landing-site-navigator/) again returned HTTP 502 to the research tool. Its complete current Objectives, Resources and submission rules therefore remain unverified; this implementation does not turn the proposed features into claimed contest requirements. PGDA Product90 and SVS3615 were accessible. Product90 specifies south-polar stereographic metres in the DE421 Moon Mean Earth frame and requests citation of [Barker et al. 2023, PSJ 4, 183](https://doi.org/10.3847/PSJ/acf3e1), with [data DOI](https://doi.org/10.60903/gsfcpgda-lola-spole). SVS3615 explicitly identifies the Earth image as an art-directed composite.

## Derived mission data

`public/data/mission-demo.json` is a reproducible example derived from the prepared SPICE dataset `de440-me421-geometric-2026-10_2027-02-v1`, not an additional observation or NASA mission recommendation. The mission module uses the existing observer-height intervals to derive visibility spans, permissible starts and limiting events. The saved expected fixture values are recomputed by tests; displayed results are computed at runtime from the actual dataset. See [mission science](mission-planning-science.md) for clipping conventions, timing limits and measured latency. No external API or language model is called to generate a mission result.

## Interpretation

Altitude measures the body centre's angle from the local reference plane. Azimuth is measured clockwise from north toward east; it is undefined at exact poles/zenith/nadir. A zero-height reference horizon differs from the visible smooth-sphere horizon at elevated height. A terrain horizon additionally depends on actual surrounding heights. Any retained reference-sphere A/B comparisons must say so when a terrain view is active. Above-horizon geometry is not electrical power, a guaranteed Earth link or a safe landing determination.

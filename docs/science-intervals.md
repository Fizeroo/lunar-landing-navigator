# Scientific visibility intervals

The science module reports intervals when the **center** of the Sun or Earth is strictly above the site's local reference tangent plane. It uses the same Moon-fixed, geometric (`abcorr=NONE`) Cartesian ephemeris and zero-height spherical site as the instantaneous observations. The result describes geometric horizon visibility; it does not model terrain, a solar panel, power, eclipse/occultation, atmospheric refraction or a radio link.

`analyzeSite(data, site, period)` accepts a finite ET period with `startEt < endEt`, wholly inside the data coverage, and a site with zero reference-sphere height. It returns independent Sun, Earth and shared-visibility summaries. Each summary contains sorted, disjoint positive-duration intervals, total seconds, the fraction of the requested period, and the longest continuous interval. Zero-duration horizon contacts do not count. An always-positive body returns the complete requested period; a never-positive body returns empty intervals and zero statistics.

For a fixed site, radial unit vector `u` and Moon radius `R`, the sign of the local up component is the sign of `dot(targetPositionM, u) - R`. Target position is linear between each pair of prepared ephemeris samples, so this scalar is linear too. The implementation solves its zero directly on every segment and clips spans to the selected period. Short visibility windows around sample nodes are therefore retained instead of being lost by sampling only the node's Boolean state. An exact-zero sample splits two positive spans: that isolated instant fails the strict condition, so intersections preserve the split and longest-duration summaries do not bridge it. Short negative gaps are preserved without a merging tolerance. This is exact for the piecewise-linear Cartesian model; event times still approximate the true sky because the source is sampled every ten minutes.

`intersectIntervals(a, b)` intersects two sorted, disjoint lists in O(n+m) time and drops zero-duration contacts. Adjacent overlap spans stay separate so a strict zero contact does not inflate the longest continuous interval. The shared visibility result is derived from the same Sun and Earth interval lists as their individual totals. Any UI should round displayed event times to minutes, describe durations as approximate, and disclose the smooth-sphere and ten-minute source model.

Focused verification command: `node --test scripts/ephemeris/intervals.test.mjs`. It includes analytic short-window, node-contact, clipping, all/none, intersection and invalid-period cases, plus a thirty-second observation-grid comparison against `observeAt` on the real November dataset. The dense grid is an independent numerical oracle for summary consistency, not a replacement ephemeris or a real-world accuracy claim.
